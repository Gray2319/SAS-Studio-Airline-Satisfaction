# Airline Passenger Satisfaction Analysis

This repository contains the final presentation for a data analytics project focused on identifying the key drivers of airline passenger satisfaction. The analysis leverages survey data and statistical modeling to uncover patterns in customer experience across different travel classes and airline services.

## Project Objective
To analyze passenger satisfaction data and generate actionable insights that airlines can use to improve service quality, enhance customer loyalty, and inform operational decisions.

## Topics Covered
- Exploratory Data Analysis (EDA)
- Feature importance and correlation analysis
- Satisfaction trends by travel class, age group, and airline type
- Predictive modeling using binary logistic and linear regression
- Strategic recommendations based on model findings

## Tools and Techniques
- SAS Studio
- Binary Logistic regression
- Linear Regression
- Excel Data visualization
- ROC Curve

## Future Directions to improve model
- Incorporating flight delay and cancellation data
- Segmenting passengers by loyalty status or route type
- Developing real-time dashboards for satisfaction monitoring
